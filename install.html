Install Project Reporting

Pick your device below. Your device is highlighted. Once it's installed, sign in with your work email.

Android phone or tablet

Open the app
  1. Open this page in Chrome.
  2. Tap Install now above. If you don't see it, tap the ⋮ menu and choose Install app (or Add to Home screen).
  3. Open OX Reporting from your home screen and sign in.

iPhone or iPad

Open the app in Safari
  1. Open the app link in Safari (Apple only allows installing from Safari).
  2. Tap the Share button (the square with an arrow ↑).
  3. Scroll down and tap Add to Home Screen, then Add.
  4. Open OX Reporting from your home screen and sign in.

Windows PC

Download for Windows
  1. Run the downloaded OX-Project-Reporting-Setup file.
  2. If Windows shows “Windows protected your PC”, click More info then Run anyway. (This shows because the app isn't code-signed yet.)
  3. Open OX Project Reporting from the Start menu and sign in.

Can't run installers on your work PC? Open the app in Edge or Chrome and choose Install from the address bar or the ⋯ menu instead.

Mac

Download for Mac (M1 or later)Download for Intel Mac

Not sure which? Apple menu → About This Mac: “Chip Apple M…” means M1 or later; “Processor Intel” means Intel.

  1. Open the downloaded zip and drag OX Project Reporting into Applications.
  2. The app isn't signed with an Apple certificate yet, so run this once in Terminal (Applications → Utilities → Terminal):xattr -cr "/Applications/OX Project Reporting.app" && codesign --force --deep --sign - "/Applications/OX Project Reporting.app"
  3. Open the app from Applications and sign in.

Prefer not to use Terminal? Open the app in Chrome or Edge and choose Install from the address bar, or in Safari choose File → Add to Dock.

Just open it in the browser

The installed app always opens the latest version, so you never need to reinstall for updates.
